# Termini per il glossario (Appendice B)

Raccolti capitolo per capitolo; la definizione finale si scrive nella sessione delle appendici.

| Termine | Capitolo | Definizione provvisoria |
|---|---|---|
| terminale | 6 | Finestra in cui si scrivono comandi testuali al computer |
| sessione | 6 | Una conversazione con Claude Code, dall'avvio all'uscita o a `/clear` |
| spinner | 6 | L'asterisco animato con il verbo in -ing che indica che Claude Code sta lavorando |
| slash command | 6 | Comando breve che inizia con `/`, per esempio `/help` |
| checkpoint | 6 | Punto della conversazione a cui si può tornare con `/rewind` |
| contesto | 6 | Tutto ciò che Claude Code ha «davanti» mentre lavora: conversazione, file letti, istruzioni |
| permesso | 6 | Conferma richiesta prima di un'azione che modifica file o esegue comandi |
